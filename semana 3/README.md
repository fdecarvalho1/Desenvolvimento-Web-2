# Pesquisa de Pokémon

## Sobre o projeto
Este projeto consiste em uma página web que utiliza a PokéAPI para buscar e exibir informações sobre Pokémon.

## Funcionalidades
- Pesquisa de Pokémon pelo nome.
- Exibição da imagem do Pokémon.
- Exibição do tipo, altura, peso e experiência base.
- Mensagem de carregamento durante a busca.
- Tratamento de erros para Pokémon não encontrado.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- PokéAPI

## API utilizada
https://pokeapi.co/

## Como executar
Abra o arquivo `index.html` em um navegador, digite o nome de um Pokémon e clique em Buscar Pokémon.
